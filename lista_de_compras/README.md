# Lista de Compras 🛒

Um aplicativo simples e eficiente desenvolvido em Flutter para gerenciar suas compras do dia a dia, ajudando no controle e organização dos seus itens.

## 🚀 Funcionalidades
* Adicionar itens rapidamente à lista.
* Marcar itens como concluídos.
* Excluir ou editar produtos adicionados.
* Interface limpa e intuitiva para uso rápido no mercado.

## 🛠️ Tecnologias Utilizadas
* **Flutter** - Framework de desenvolvimento cross-platform.
* **Dart** - Linguagem de programação padrão do Flutter.

## ⚙️ Como Executar o Projeto Localmente

### Pré-requisitos
Antes de começar, certifique-se de ter o Flutter instalado na sua máquina.

### Passo a passo
1. Clone este repositório no seu computador:
   ```bash
   git clone https://github.com/JEFHDEV/lista_de_compras.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd lista_de_compras
   ```
3. Instale as dependências necessárias:
   ```bash
   flutter pub get
   ```
4. Execute o aplicativo:
   ```bash
   flutter run
   ```
